## How to add yourself (Issue #2)

1. Fork this repository and create a new branch:
   ```bash
   git checkout -b add-contributor-yourname
   ```
2. Add your name and details to the list below following this format:
   ```markdown
   - **[Your Name](https://github.com/your-username)** - Your Role/College | Favorite Gadget or Book: *Your Choice*
   ```
3. Commit and open a Pull Request!
